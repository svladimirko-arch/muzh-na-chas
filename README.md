# МУЖНАЧАС — лендинг «муж на час»

Одностраничный сайт услуги: выбор услуги → прайс → выбор мастера → заявка с календарём свободных окон.

## Публикация

Сайт живёт на GitHub Pages: ветка `gh-pages` собирается из папки `dist`.

## Локальный запуск

```bash
npm install     # один раз
npm run dev     # разработка: http://localhost:5173
npm run build   # сборка в dist/
npm run preview # просмотр сборки
```

## Где менять данные

Все тексты, цены, контакты и мастера — в одном файле: `src/data/catalog.ts`:

- `COMPANY` — название, телефон, почта, Telegram, город, часы работы
- `SERVICES` — услуги и прайс-листы
- `MASTERS` — мастера: имена, описания, рейтинги, навыки
- `HERO_STATS` — цифры в шапке страницы
- `ORDER_ENDPOINT` — адрес API для приёма заявок (пусто = демо-режим)

Свободные окна в календаре генерируются стабильно из пары «мастер + дата»
(`src/lib/helpers.ts`) — при подключении реального расписания заменяется одной функцией.

## Стек

React 18 + TypeScript + Vite 5. Без платных сервисов.
